# 慢光速实验室 · Slow Light Lab

**当光速只有 10 m/s，世界会是什么样？**

一个纯离线的第一人称狭义相对论驾驶模拟器。在熟悉的街角加速，亲眼看到光行差扭曲视野、迎面的灯蓝移、身后的尾灯红移，并亲身感受"越接近光速越加不动"的速度极限。

## ✨ 功能特性

- **真实相对论动力学**：动量 `p = γmv`，纵向惯性按 `γ³` 增长——保持同样的推力，0.9c 时同向加速能力只剩静止时的 **8.3%**
- **三种视图模式**
  - 📷 **光学所见**：逐像素计算的相对论光行差（你"看到"的世界）
  - 📏 **长度测量**：观察者同刻空间，沿运动方向压缩至 `1/γ`（你"测得"的世界）
  - ⚪ **普通对照**：关闭几何变换，用于直观对比
- **相对论多普勒效应**：迎面蓝移、背后红移；波长超出可见光范围时用伪彩标记
- **前后双视野**：主视野与后视视野同时渲染，红移蓝移一屏对比
- **自动演示**：一键播放完整的加速、制动与视效演示
- **手动 β 输入**：直接设定速度；非法输入（≥c、NaN、Infinity）被原子化拒绝，永远保持亚光速

## 🚀 运行

双击 `index.html` 即可。无需安装、无需联网、无构建步骤，任何支持 WebGL 的现代浏览器（Chrome / Edge / Safari）均可打开。

## 🧪 回归测试

`physics.cjs` 会在 Node 中以 VM 抽取 HTML 里的模拟核心，与相对论解析解逐项对照（洛伦兹因子、多普勒、光行差逆映射、动量—速度数值导数、强制动停止时间、长度收缩、自动演示完整流程）：

```bash
mkdir dist && copy index.html dist\index.html   # Windows
node physics.cjs
# PASS: dynamics, subluminal manual beta, invalid-input atomicity, ...
```

## 📁 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 完整应用：页面、模拟逻辑、UI 全部内嵌于单文件 |
| `renderer-source.js` | 自研 WebGL 渲染器源码（立方体环境贴图 + 光行差 / 多普勒着色器），由本地构建步骤内嵌进 HTML |
| `physics.cjs` | Node 回归测试，运行前需 `dist/index.html`（见上） |
| `hosting.json` | 静态托管平台部署配置（`dist/` 目录） |
