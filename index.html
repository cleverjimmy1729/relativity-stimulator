这个世界，如何运行？

光速 c = 10 m/s，人物静质量 m₀ = 60 kg。街景、公交车和装饰人物都静止于街区系，观察者可自由施力与转向。所有资源、纹理和程序均内嵌，可断网打开。

01 / 光学所见：沿光锥观察

cos θ′ = (cos θ + β) / (1 + β cos θ)
D = γ(1 + β cos θ) = 1 / [γ(1 − β cos θ′)]

θ 是街区系中物体方向与速度的夹角，θ′ 是眼睛实际看到的角度。高速运动使更多侧方甚至后方的景物出现在运动前方；建筑轮廓、道路和天空都会变形。渲染器先获取观察点周围六个方向的街景，再对每个输出像素反解洛伦兹光行差，找到实际的街区光线。速度方向与身体朝向彼此独立。

对本演示中的静态场景，这种光线方向变换等价于在观察者瞬时惯性系追踪过去光锥：已经包含静态景物的光程时间差与相对论外观，不能再把建筑简单压扁一次。动画行人、运动公交等非静态光源尚未加入。

02 / 长度测量：观察者的同一时刻

r′ = r⊥ + r∥ / γ　　L∥ = L₀ / γ
γ = 1 / √(1 − β²)　　横向长度保持不变

切换到“长度测量”，沿当前速度方向压缩整个街区的空间坐标。此视图展示在观察者系中同时测量的位置，不是一张光学照片。右侧标尺比较一把沿速度方向放置、静长 20 m 的尺子。例如 β = 0.9 时 L = 8.72 m。“普通对照”关闭几何变换，方便在同一位置比较；红蓝移开关独立控制颜色。

03 / 多普勒颜色与画质

λobs = λ₀ / D　　参考绿光 λ₀ = 550 nm

主视野和后视窗读数都使用对应视线经过当前几何变换后的真实光线方向。红蓝移不再按整个面取一个颜色：每个像素单独计算 D，路面和建筑保留纹理、明暗与材质差别。纹理包括沥青颗粒、步道铺砖、墙砖和玻璃反射示意；“高清 2× / 超清 3×”按画面 CSS 尺寸提高实际渲染分辨率。

颜色仍是保留亮度的频移示意，并非从 RGB 材质精确还原完整光谱；紫外和红外继续显示为可辨别的示意色。完整光谱、相对论亮度增强与自动曝光未模拟，因此适合观察方向、形状与频移趋势，不用于预测真实相机色彩。

04 / 动力学、强制动与 β 输入

dp/dt = F　　v = p / (γm₀)
γ = √(1 + |p|² / m₀²c²)
同向加速度 a = F / (γ³m₀)　　E/c² = γm₀

W / S 沿身体朝向施加街区系中的力。A / D 只转动身体；松手没有阻力，因此会滑行。静质量 m₀ 不变，“相对论质量”是 E/c² 的传统表述，不是人物体积膨胀。

B 强制动使用自适应反向力，按街区系减速度 12 m/s² 降低速度；从任意亚光速持续制动，约 0.84 s 内停止，且不会倒车。越接近光速，制动力越大，实际数值显示在右侧。S 保持普通反向施力，方便比较二者。建筑接触仍采用简化停车。

手动输入 0 ≤ β < 1 后按“设定”或 Enter，可沿身体朝向瞬时设置速度。该功能用于比较，不代表真实加速过程；β = 1、负值、空值与无穷均不接受。街区时钟以 dt 累计，自身固有时以 dτ = dt / γ 累计。自动演示可用方向键接管。
